# 无线麦 SayAll · Mac mini 睡眠隔离实验版

[English](README.en.md)

由 **yigiaogiao** 个人维护，基于 [HD838A/remote-mic-app](https://github.com/HD838A/remote-mic-app) 修改。本项目用于探索小米 RC003 蓝牙遥控器在 Mac mini 上的睡眠隔离和唤醒后连接恢复，不属于上游正式版本。

## 为什么做这个版本

本机连接小米遥控器后，曾在没有按键操作的情况下被自动唤醒。本分支尝试在系统准备睡眠时隔离选定遥控器，保留配对，并在完全唤醒后恢复连接。屏保不单独触发隔离，不修改全局蓝牙开关或系统睡眠时间。

## 当前状态与适用范围

- 目前只有维护者本人一台 Mac mini 的正向使用反馈，不能保证其他 Mac mini 或其他 Mac 型号有效。
- 依赖未公开的 macOS CoreBluetooth 选项。应用收到断开回调，不代表设备已被移出系统唤醒源。
- 上游作者在 MacBook Pro 上独立测试相同隔离路径，两次仍出现蓝牙 HID 导致的完全唤醒。这是明确的失败案例；本项目不宣称通用修复。
- [上游 PR #778](https://github.com/HD838A/remote-mic-app/pull/778) 已关闭。本仓库保留实验源码供个人使用和研究。

## 本分支的修改

- 默认关闭的 RC003 单设备睡眠隔离选项，设备标识只存本机。
- 隔离期间暂停目标遥控器的应用重连；完全唤醒、显示器点亮且控制台会话活跃后请求恢复。
- 本地候选 **2.0.0 / 267.3** 持续发现待恢复目标，缩短原先可能达到一分钟的扫描空档。
- 清醒时目标意外断连的一次有界快速恢复，以及连接阶段耗时日志。

267.3 的实际唤醒恢复提速和睡眠回归仍待验证；单元测试和启动连接成功不能替代这些实机验证。完整 SwiftPM 测试仍受本机 XCTest 环境限制。

## 安装与使用

**目前只提供源码，没有在此发布实验版安装包。** 源码中的上游版本字段不代表已发布 267.3；原作者官网的下载也不包含本分支修改。

已经安装本地候选的用户：

1. 打开“连接与语音”，选中已配对的 RC003 遥控器。
2. 启用“系统睡眠时隔离此遥控器（实验性）”，保持应用运行。
3. 用其他输入设备唤醒 Mac 后，按遥控器按键使其响应；不保证固定时间内连接。
4. 关闭该选项可停止后续睡眠隔离。需要回退时，先退出实验应用，再运行原版，避免两者同时控制设备。
